Eco_Tracker_IA — Helios

FastAPI PostgreSQL Vue 3 Chart.js Python

Combien d'énergie consomme ta requête ChatGPT ? Ce dashboard te le dit — en équivalents concrets.

L'objectif

L'IA a un coût énergétique invisible. Helios le rend lisible, comparable, et pédagogique.

Blocs de contenu
  • API FastAPI + SQLAlchemy + PostgreSQL, dashboard Vue 3 + Chart.js
  • Comparaison infrastructure standard vs éthique
  • Projet Bachelor en groupe — contribution personnelle : sandbox Helios + premier commit repo groupe
Difficulté

Les données de consommation par modèle IA ne sont pas publiques — estimation et approximation nécessaires.
Trouver des données fiables et les rendre compréhensibles sans noyer l'utilisateur.
