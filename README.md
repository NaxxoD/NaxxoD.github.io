# Portfolio

Site statique présentant mon parcours et mes projets.

**Voir le site : https://naxxod.github.io**

## Contenu

- `index.html` : présentation, projets et contact
- `projets/` : une page par projet
- `css/` et `js/` : mise en forme et interactions
- `assets/` : images et polices

## Lancer en local

Ouvrir `index.html` dans un navigateur. Aucune dépendance à installer.
