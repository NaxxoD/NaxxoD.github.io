Next.js React TypeScript Tailwind CSS Pédagogie Cryptographie

Apprendre la cryptographie en jouant — sans avoir besoin de coder.

L'objectif

La crypto, c'est abstrait. STL transforme les concepts en niveaux interactifs avec validation par IA.

Blocs de contenu
  • Stack : Next.js + React + TypeScript + Tailwind CSS
  • Déployé sur Vercel — accessible sans installation
  • Validation des réponses par LLM (sémantique, pas juste format)
  • Présenté en soutenance académique
Difficulté

La validation IA était trop rigide — elle rejetait des bonnes réponses mal formulées. V2.0 vise une compréhension sémantique.
